# Code de conduite

## Notre engagement

Contributrices, contributeurs et mainteneurs de PerfIA Diagnostic IA s'engagent à faire de la participation au projet une
expérience sans harcèlement pour toutes et tous, quels que soient l'âge, le handicap visible ou invisible, l'origine,
l'identité ou l'expression de genre, le niveau d'expérience, la formation, la situation socio-économique, la
nationalité, l'apparence, la religion ou l'orientation sexuelle.

## Ce que nous attendons

- Faire preuve de bienveillance et de patience, en particulier avec les personnes qui découvrent le projet.
- Respecter les opinions, les points de vue et les expériences différentes.
- Donner et recevoir les critiques de manière constructive, en parlant du code et des idées, pas des personnes.
- Reconnaître ses erreurs, s'excuser auprès des personnes concernées et en tirer les leçons.
- Privilégier ce qui est le mieux pour la communauté plutôt que pour soi.

## Ce que nous refusons

- Les propos ou images à caractère sexuel, et les avances de toute nature.
- Le trolling, les commentaires insultants ou dégradants, les attaques personnelles ou politiques.
- Le harcèlement, public ou privé.
- La publication d'informations privées d'autrui (adresse, e-mail) sans son autorisation explicite.
- Tout autre comportement qui serait raisonnablement jugé inapproprié dans un cadre professionnel.

## Périmètre

Ce code s'applique dans tous les espaces du projet (issues, pull requests, revues, discussions) et lorsqu'une
personne représente officiellement le projet ailleurs.

## Signalement

Signalez un comportement contraire à ce code aux mainteneurs, par un message privé à un membre de l'organisation
[Kosmio](https://github.com/Kosmio) sur GitHub, ou via [kosm.io](https://kosm.io). Chaque signalement est examiné
rapidement et avec discrétion ; la personne qui signale est protégée.

## Mesures

Selon la gravité, les mainteneurs peuvent : demander de corriger un comportement, adresser un avertissement,
exclure temporairement ou définitivement une personne des espaces du projet. Les mainteneurs qui ne respectent pas
ce code s'exposent aux mêmes mesures.
